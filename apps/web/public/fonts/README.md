# Self-hosted UI fonts

Manrope (variable, weights 400–800) and IBM Plex Mono (regular), Latin subsets.
Served locally so PiHomeHub needs no external font request on a private network.

Sources: Google Fonts / Google Fonts repository.

- https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSg.woff2
- https://fonts.gstatic.com/s/ibmplexmono/v23/-F63fjptAgt5VM-kVkqdyU8n1i8q1w.woff2
- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/ibmplexmono
